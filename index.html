Instalar VectorSlice.jsx
Opción A — Uso puntual
1 Descarga el archivo VectorSlice.jsx con el botón de arriba.
2 Abre tu documento en Adobe Illustrator con los paths a convertir.
3 Ve a File → Scripts → Other Script… y selecciona el archivo descargado.
4 El script generará el XML y abrirá un diálogo para guardarlo.
Opción B — Acceso directo desde menú
1 Copia VectorSlice.jsx en la carpeta de Scripts de Illustrator según tu sistema:
macOS
/Applications/Adobe Illustrator [versión]/Presets/en_US/Scripts/
Windows
C:\Program Files\Adobe\Adobe Illustrator [versión]\Presets\en_US\Scripts\
2 Reinicia Illustrator. El script aparecerá en File → Scripts → VectorSlice.
Nota sobre idioma: La ruta usa en_US para instalaciones en inglés. Si tu Illustrator está en otro idioma, sustituye en_US por el código de tu idioma (p. ej. es_ES para español).
